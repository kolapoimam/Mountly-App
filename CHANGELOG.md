# Changelog

## 1.0.0

First public release.

- Instant detection of external drives through Disk Arbitration
- NTFS read and write through macFUSE and NTFS-3G, with guided setup
- Automatic write checks for exFAT, FAT32, APFS and HFS+
- Clear drive states, including dirty and hibernated NTFS volumes
- Copy to and from drives with progress, conflict handling and cancel
- Safe eject for one or all drives
- Menu bar access, Diagnostics screen and Settings
