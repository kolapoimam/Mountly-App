# Mountly: External drives, made accessible.

Mountly gives your Mac a simpler way to work with external filesystems that macOS doesn't fully support out of the box. Free, open source, and built for your hardware.

## Everything you need. Nothing you don't.

A lightweight, focused utility designed to make external filesystems seamless on Mac.

- **NTFS Read & Write**: Enable full read and write access on NTFS formatted external drives without terminal commands or reformatting.
- **Finder Integration**: Discovered volumes appear right in macOS Finder so you can browse, copy, and organize files naturally.
- **Safe Volume Operations**: Protected mounting routines and safe eject ensure existing partition journals remain undamaged.
- **Universal Hardware Support**: Compatible with any external enclosure: USB-C, USB-A, portable SSDs, mechanical HDDs, and flash media.

## Built for your filesystems and drives.

Mountly handles supported external filesystems while respecting native macOS operations.

| Filesystem | Status | Access mode | Notes |
| --- | --- | --- | --- |
| NTFS | Supported | Read & Write | Windows volumes mounted with full read/write support enabled. |
| exFAT | Native | Native macOS | Cross-platform standard supported natively by macOS out of the box. |
| APFS | Native | Native macOS | Apple File System standard for modern macOS media. |
| FAT32 | Native | Native macOS | Universal legacy format supported natively by macOS. |
| HFS+ | Native | Native macOS | Mac OS Extended standard supported natively by macOS. |
| EXT4 | Limited | Read Only | Linux standard filesystem with read support. |

**Apple Silicon & Intel Universal Binary.** Optimized for M1/M2/M3/M4 & Intel 64-bit Macs running macOS 13 Ventura or newer. AppKit native. Kernel extension not required.

## Frequently Asked Questions

### What is Mountly?
Mountly is a native macOS utility designed to detect, mount, and manage supported external drives and filesystems with seamless Finder integration.

### Does Mountly support NTFS write access?
Yes. Mountly enables supported read and write operations on NTFS drives without requiring terminal commands or kernel extension hacks.

### Do I need to format or erase my drive?
No. Mountly is built so you never have to erase or reformat an existing drive simply because you plugged it into a Mac.

### What types of drives are supported?
Mountly works with any external enclosure — USB-C, USB-A, external SSDs, mechanical hard drives, and flash cards regardless of brand.

### Does Mountly modify or collect my files?
No. Mountly runs entirely offline on your Mac, collects zero telemetry, and performs operations strictly requested by you.
